# Jan Ivan Andrade — Systems in Motion

A plain HTML, CSS, and JavaScript career portfolio presented as an editorial field guide to systems administration. The original midnight navy, cool white, cyan, and teal palette is retained.

## Files
- index.html — semantic page structure, career pathway, roadmap, tools, roles, and profile
- styles.css — responsive editorial layout, typography, motion, and reduced-motion treatment
- script.js — career milestone selector, skill index and checklist, certification search/filter/details, resource index, technology showcase, and active section navigation

## Run locally
Open index.html directly in a browser. There is no build step or framework dependency. Google Fonts load when an internet connection is available; system sans-serif fallbacks are provided.

## Content
The portfolio preserves the existing certification pathways and their official links, learning resources, skill topics, and Jan’s existing student profile information. Its required sections cover System Administrator certifications, the value of continued professional development, skills and qualifications, learning resources, and the developer profile. Career responsibilities and tool descriptions are explanatory portfolio content, not claims of personal work experience or certification.
